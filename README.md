simple program emulating dynamic arrays for ints and python-like list operations in c, features basic terminal-based ui for providing arguments etc. tbh just a memory management excercise

project structure:
* `main.c` –  main loop and user interface
* `array.c` – array logic, sorting, algorithms
* `array.h` – Header file with structures, enums, and function prototypes
* `CMakeLists.txt` – makes building the project a breeze

requirements
* a C compiler supporting C99 (GCC, Clang, MSVC)
* CMake (version 3.10 or newer)
